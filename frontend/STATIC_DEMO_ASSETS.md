# Изображения статичной демонстрации

Страница `/avito` является учебным статичным макетом. Поиск, оплата, переписка и размещение объявлений на ней не выполняются.

## Работа без внешних ресурсов

- критичные баннеры хранятся локально в `src/assets/avito-demo`;
- локальные растровые assets оптимизированы в WebP;
- компонент `ImageWithFallback` заменяет недоступные изображения карточек локальным placeholder;
- если не загружается аватар, интерфейс сохраняет цветной круг с инициалами;
- вместо внешнего Avito Sans используется локальный `Inter Variable` из npm-пакета;
- текст, цена и категория не зависят от загрузки изображения.

В `avitoStatic.ts` пока остаются внешние URL изображений для визуального сходства с прототипом. Они используются только как необязательный источник: при сетевой ошибке отображается локальный fallback.

## Правовой статус

Локальные fallback-изображения сгенерированы специально для проекта, не содержат сторонних логотипов, надписей или скопированных изображений Авито. Внешние материалы не сохранены в репозитории.
